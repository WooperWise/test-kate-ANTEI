# Отчёты прогонов Harness

Готовые артефакты финальных живых прогонов (2026-09-30) на локальном vLLM
`Qwen3.8-27B-FP8` с реальными данными PubMed / Europe PMC / ClinicalTrials.gov.
Полные журналы событий — в `outputs/run_<id>.jsonl` при воспроизведении прогона.

| Запрос | Отчёт | Studies | Статус | Журнал прогона |
|---|---|---|---|---|
| Широкий: митохондриально-таргетные препараты (MitoQ, SkQ1, эламипретид, уролитин A, NAD⁺-прекурсоры, гентерапия LHON) vs стандарт при PMD / LHON / ХСН, 2021–2026 | [reports/broad/report_broad.md](broad/report_broad.md) | 25 | ok | `run_9784b8f239` |
| Узкий: перспективность NAD⁺-прекурсоров (NR/NMN) и уролитина A при митохондриальной дисфункции, 2021–2026 | [reports/narrow/report_narrow.md](narrow/report_narrow.md) | 19 | ok | `run_45b85fb48b` |

Каждый отчёт — мини-обзор на русском: резюме, методы Harness, сравнительная
матрица (митотерапия vs стандарт), скоринг перспективности с компонентами,
аутсайдеры, ограничения, верифицированные ссылки (PMID/NCT) и секция
«Отклонено ревьюером» (утверждения, не прошедшие проверку цитирования).

> **Кросс-прогонная коррекция (broad).** Ревьюер narrow-прогона доказательно
> установил, что PMID 42616901 («Targeting PKGIα Cys42…», HFpEF) не является
> исследованием уролитина A. В broad-отчёте эта запись использовалась как
> доклиническое доказательство по уролитину A — она удалена из текста,
> матрицы и ссылок, а графики `effect_direction.png` и `gap_map.png`
> перерисованы из закэшированного результата сравнения без этого PMID
> (детерминированный replay, без LLM-вызовов). Это демонстрирует ценность
> перекрёстной валидации между прогонами Harness.

Графики (рядом с каждым отчётом):

- `effect_direction.png` — направления эффектов по исходам (один маркер = одно исследование; цвет = уровень доказательности; аннотации PMID/NCT);
- `prospects_ranking.png` — рейтинг направлений с разбивкой по компонентам скоринга (веса — в `skills/prospects_criteria`);
- `gap_map.png` — карта доказательности «вмешательство × заболевание».

Воспроизведение: `uv run python main.py` (см. README); повторный прогон тех же
запросов replay'ится из кэша за минуты, `--refresh` — полный live-режим.
